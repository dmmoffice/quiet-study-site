# Quiet Study website

Official website, privacy policy and support for **Quiet Study**, developed by **damemo**.

This repository contains only the public website. No extension runtime, student data, recordings, backups or private reference artwork is included.

## Pages

- Home: index.html
- Privacy: privacy.html
- Support: support.html

Static HTML and CSS, with local images. No build step, analytics, external fonts or JavaScript. Publish through GitHub Pages from main / (root). Keep .nojekyll in the publishing root.

Support and general privacy questions: use this repository's Issues page. Issues are public; do not submit credentials, student identifiers, grades, recordings or unredacted screenshots.
