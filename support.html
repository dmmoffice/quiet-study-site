Getting started

  1. Open your signed-in Canvas dashboard.
  2. Click the Quiet Study extension and connect your school. Standard Instructure sites are supported; custom Canvas domains request a permission for that school site.
  3. Open Edit Canvas to choose a theme or customize cards. Optional widgets start off; enable the ones you want.
  4. Use the sample workspace to explore with synthetic data before connecting your school.

Something looks wrong?

The dashboard did not update

Refresh Canvas after an extension update. Check that the Canvas appearance switch is on. If you use another Canvas appearance extension, pause it while comparing designs.

Progress numbers seem different

Compare the same date range and course filters. Day, Week, Month and Custom affect the tracker and the due work shown on cards. Local grade and GPA tools provide estimates; Canvas remains the source for official grades.

I want to move or remove my data

Export a backup from Settings before switching installations. Import it into your new installation. Reset clears app data; uninstalling removes extension storage. Delete downloaded backups and exports separately.

Do I need microphone or notification access?

Those features are optional. Microphone permission is requested when you start recording. Desktop notifications can be enabled separately. The rest of the extension works without them.

Report a bug or ask a question

Use the project’s GitHub Issues page for support, feature requests and general privacy questions. Include your extension version, Chrome version, what you expected and the steps that caused the issue.

GitHub Issues are public. Leave out passwords, tokens, student identifiers, grades, private notes and recordings. Crop or redact screenshots before sharing them.
